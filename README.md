## STOPS viewer

Web viewer for output files from FTA STOPS model. The STOPS model produces thousands of pages of output, and finding it in a text file. This tool allows browsing output tables in an interactive viewer rather than slogging through pages of output. [Access the tool here](https://projects.indicatrix.org/stopsviewer).

This is beta software, use at your own risk and please report any bugs.
