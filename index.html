STOPS Report Viewer

View FTA STOPS model output reports as accessible tables. Files are read on your computer and are not uploaded.

Open report files

Choose one or more STOPS report files, or drag and drop them onto this page. Each file opens in its own tab.

Use the left and right arrow keys to switch files. Press Delete to close the selected file.

No files open

After you open a file, its table of contents is listed by report section. Select any table to view it. Use Back to table of contents or press Escape to close the table and return to the list.

Beta software: use at your own risk. Always verify results against the original STOPS report files.
